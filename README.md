# Personal Mini-Toolkit

## Project Description
The Personal Mini-Toolkit is a Python program that brings together three useful tools in one menu-driven application.

### Features
1. **Simple Calculator** – Performs addition, subtraction, multiplication, and division.
2. **To-Do List** – Allows users to add, view, and remove tasks.
3. **Number Guessing Game** – Challenges users to guess a randomly generated number between 1 and 10.

## How to Run the Program

1. Open the project folder in your terminal.
2. Run the following command:

```bash
python3 toolkit.py
```

3. Follow the instructions displayed in the menu.

## Project Files
- `toolkit.py` – Main Python program.
- `toolkit_plan.txt` – Initial project plan.
- `screenshots/` – Screenshots showing the tools in action.

## Reflection

The most challenging part of this project was understanding how to organize the different tools within one main menu using loops and conditional statements. The trickiest issue I worked through was indentation and ensuring that each tool returned to the main menu correctly. I also had to make sure that tasks remained available while the program was running. Through this project, I improved my understanding of Python lists, loops, functions of conditional statements, user input, and error handling. I enjoyed building the calculator, To-Do List, and Number Guessing Game because each introduced a different programming concept. If I had another week, I would improve the To-Do List by allowing tasks to be saved permanently in a file and add more useful tools to the application.
